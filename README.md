# 🎓 Sistem Informasi Bimbingan Skripsi UMSU

Sistem Informasi Bimbingan Skripsi adalah platform berbasis web yang dirancang untuk mempermudah dan memdigitalisasi proses administrasi, penjadwalan, serta rekapan bimbingan tugas akhir/skripsi antara mahasiswa dan dosen pembimbing di Universitas Muhammadiyah Sumatera Utara (UMSU).

---

## 🚀 Fitur Utama

### 👨‍🎓 **Panel Mahasiswa**
* **Pengajuan Bimbingan:** Mengajukan jadwal bimbingan dan mengunggah draf skripsi secara online.
* **Monitoring Progres:** Melacak status persetujuan, revisi, dan log histori bimbingan secara *real-time*.
* **Manajemen Dosen Pembimbing:** Melihat informasi dosen pembimbing yang ditugaskan.

### 👨‍🏫 **Panel Dosen Pembimbing**
* **Manajemen Pengajuan:** Menerima, menolak, atau menjadwalkan ulang *booking* bimbingan dari mahasiswa.
* **Review & Catatan Revisi:** Memberikan masukan, catatan, serta status persetujuan draf skripsi.
* **Daftar Bimbingan Active:** Mengelola daftar mahasiswa bimbingan yang sedang aktif.

---

## 🛠️ Tech Stack

* **Backend:** [Laravel](https://laravel.com/)
* **Frontend:** Vue.js / Inertia.js / TypeScript
* **Database:** MySQL
* **Styling:** Tailwind CSS
